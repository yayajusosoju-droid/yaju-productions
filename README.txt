# YAJU PRODUCTIONS Portfolio

## How to use
1. Open `index.html` in any browser.
2. Edit the text directly in the file using VS Code, Notepad++, or another editor.
3. Replace the portfolio placeholder blocks with your own images.
4. To use an image, replace a placeholder like:
   `<div class="project-image"><span>YOUR PROJECT 01</span></div>`
   with:
   `<div class="project-image"><img src="images/my-project.jpg" alt="Description"></div>`
5. Put your images inside an `images` folder next to `index.html`.

The website is responsive and includes working navigation, portfolio category filters, and an email contact button.
